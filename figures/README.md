# Generated figures

This directory contains the six article figures. Each PNG is rendered
exclusively from the corresponding machine-readable table under `data/` by
`scripts/plot_all.py`.

The plotting module preserves the article's visual conventions, including
serif/Computer Modern typography, Matplotlib `C0`–`C3` colors, line and marker
styles, panel dimensions, and the Fisher-uncertainty inset. The figures are
licensed under CC BY 4.0.
